# Нейросети для проектирования: от чата до ассистента

Лендинг курса Евгения Коцура. HTML, CSS и небольшой JavaScript без сборщика и внешних библиотек в браузере.

## Просмотр

Откройте `index.html` двойным щелчком. Для просмотра через HTTP нужен установленный Node.js:

```powershell
node scripts/preview.mjs
```

Адрес: http://127.0.0.1:4317/. Для проверки без JavaScript: http://127.0.0.1:4317/?nojs=1. Сервер доступен только на этом компьютере и отдаёт только разрешённые публичные файлы. Остановка — Ctrl+C.

Для сравнения композиций есть второй вариант ключевых блоков: `design/variant-b.html`. Он доступен через локальный сервер по тому же пути. Основной вариант реализован в `index.html`; вариант Б в папку публикации не входит.

## Что реализовано

- Инженерная тёмная композиция по принципам AWE/Dala, авторские SVG-схемы.
- Программа: подготовка 00 и пять модулей 01–05 с раскрытием содержания.
- Расписание пяти занятий, скачиваемый календарь, открытая встреча.
- Два подтверждённых уровня цены без выдуманного остатка мест.
- Подготовка заявки на курс или встречу, просмотр и копирование текста, переход в личный чат Евгения. Сайт не отправляет сообщение за посетителя и не подтверждает оплату.
- Прямые контакты работают при отключённых скриптах. Программа и вопросы используют нативные `details`.
- Сведения о сроках ДЗ, выдаче материалов, записях и персональном просмотре PDF.
- Метаданные ссылки, локальное изображение предпросмотра, sitemap, robots и фавиконка.
- Адрес `/calc/` сохранён; его содержимое не переделывалось.

## Запись и оплата

Выбрана ЮKassa. До подключения кабинета работает подготовка заявки и согласование индивидуального счёта с Евгением. Платёжные ссылки, ключи и фактические оплаты в этой версии отсутствуют.

После подключения организатор подтверждает свободное место, цену и условия, создаёт счёт в ЮKassa, сверяет результат в кабинете, оформляет чек НПД и открывает учебные доступы. Прямой автоматический платёж, фиксация остатка мест и автоматическая выдача доступа не реализованы. Подробности и необходимые проверки: `docs/запуск-лендинга.md`.

Formspree не используется. Имена и вопросы готовятся в открытой вкладке; переход в Telegram происходит по отдельному нажатию посетителя. Платные PDF, закрытые ссылки Google Диска, реестр учащихся и ключи в папку публикации не входят.

## Проверка и подготовка публикации

```powershell
python scripts/check-site.py
node --test scripts/build.test.mjs
node --check js/main.js
node scripts/build.mjs
```

Если команда `python` недоступна, укажите путь к установленному Python 3.10 или новее. Скрипт проверки использует только стандартную библиотеку.

Готовая папка: `dist/course/`. Публиковать её содержимое, а не корень репозитория. Сборка копирует явный список файлов и прекращает работу при обнаружении постороннего файла в папке публикации. Файлы не удаляются автоматически. Установка npm-пакетов не требуется.

Проверить именно папку сборки можно через `node scripts/preview.mjs --dist` по адресу http://127.0.0.1:4318/. После запуска сравните её с HTTP-ответами: `& './scripts/check-published.ps1' -BaseUrl 'http://127.0.0.1:4318/'`. После публикации подставьте адрес домена.

Лендинг опубликован 11 ноября 2026 года на `https://evgeniikotsur.ru/`. Обновление выполняется командой `git push origin main`: существующий вебхук GitHub запускает выкладку на VPS. После публикации проверены все 11 файлов сборки, включая календарь и `/calc/`.

Домен в canonical, sitemap и метаданных — `evgeniikotsur.ru`. Подключение кабинета ЮKassa и пробный заказ с чеком и учебными доступами остаются следующим этапом.

## Структура

- `index.html`, `css/style.css`, `js/main.js` — лендинг.
- `images/course-*.svg` — редактируемые авторские иллюстрации; PNG — изображение для ссылки.
- `course-schedule.ics` — пять субботних занятий 10:00–13:00 МСК.
- `scripts/` — просмотр, проверка и подготовка публикации.
- `docs/` — программа, исследование и порядок запуска; не публикуются.
- `памятки/` — личная память проекта, исключена из Git.

Фото и расширенная биография ведущего ожидаются от автора. Сейчас используется типографическая монограмма; вымышленных фотографий, отзывов и результатов учеников нет.
