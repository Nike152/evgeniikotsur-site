# Подготовка к подаче уведомления РКН

14 ноября 2026 года в браузере проверены официальные страницы и незаполненная бумажная форма. Данные владельца в сервис не вводились, уведомление и черновик на портале не отправлялись. Это инструкция для подготовки; окончательные сведения оператор сверяет перед подачей.

## Как подать

На [официальной странице выбора способа](https://pd.rkn.gov.ru/operators-registry/notification/form/) есть три варианта:

- Через подтверждённую учётную запись Госуслуг: после заполнения и отправки бумажная копия не требуется. Это предлагаемый путь для владельца, если такая запись есть.
- С усиленной квалифицированной электронной подписью. Установка средств подписи ради этого проекта не выполнялась.
- Бумажный вариант: отправка электронной формы с последующей печатью, подписью и направлением в территориальный орган. Кнопка подготовки к печати одновременно отправляет электронное уведомление; это не локальный предварительный просмотр.

На портале отдельно предупреждено об общедоступности сведений об ответственном за обработку. Контакты для такого поля нужно проверить перед отправкой. Личные адрес и телефон находятся только в закрытой карточке организатора; в Git их нет.

## Сопоставление с проверенной формой

| Поле | Что подготовлено или нужно уточнить |
| --- | --- |
| Регион регистрации | Проверить по адресу регистрации владельца. Сообщённый контактный адрес в Воронеже сам по себе не подтверждает регистрацию |
| Тип оператора | Для самозанятого без статуса ИП — «Физическое лицо». После выбора форма показывает отдельные поля ФИО и документа; обязательность отмечена на самой форме |
| Документ и СНИЛС | При необходимости владелец вводит непосредственно в официальной форме; в пакет и чат эти данные не собирать |
| Адрес и почтовый адрес | Из закрытой карточки после проверки регистрации, индекса и адреса для корреспонденции |
| Регионы обработки | Учесть работу оператора и подтверждённое размещение базы; сверить полный состав, не ограничиваться местом жительства |
| Цели | Для каждой цели отдельно задаются данные, субъекты, основание, действия и способ обработки. Заготовка — в [карточке сведений](../черновики/сведения-для-уведомления-ркн.md) |
| Категории данных | Выбирать только фактически нужные. В форме отдельно есть обычные фото/видео и голос, а также биометрические данные для установления личности. Не объединять эти поля автоматически |
| Категории субъектов | В форме есть клиенты, посетители сайта и учащиеся. Сопоставить с каждой целью проекта |
| Действия | Сбор, запись, хранение, использование и другие фактические операции. Закрытый доступ участникам не требует автоматически отмечать публичное распространение |
| Способ | Электронные сервисы и Интернет используются; ручное ведение таблицы не означает обработку без средств автоматизации |
| Организационные и технические меры | Указывать действующие меры, описанные в карточке. Полного обследования и определения уровня защищённости пока нет; не заявлять наличие сертификатов или выполненную оценку без оснований |
| Криптографические средства | На сайте и при SSH фактически используются защищённые соединения. Поле не заполнять автоматически значением «не используются»; формулировку сверить с составом системы |
| Ответственный | Владелец работает один. Перед отправкой проверить контактные поля и предупреждение об их общедоступности |
| Дата начала | План заявок — 16 ноября; фактическая техническая обработка началась раньше. Точная дата ещё не установлена, см. ниже |
| Прекращение обработки | Условия зависят от цели: 90 дней, пять лет, срок доступа к материалам и установленный срок записей. Одной даты окончания курса для всех целей недостаточно |
| Трансграничная передача | Отдельно определить получателей, страны и правовой порядок Google, Telegram и Gmail; российский VPS не отвечает на этот вопрос |
| Место базы | Страна РФ; полный физический адрес ЦОД нужно подтвердить для конкретного VPS. Сегмент `ru-3b` подтверждает регион Санкт-Петербург, зону 1, но не полный адрес |
| Собственный ЦОД | Для арендуемого VPS — «нет». После выбора появляются сведения об организации, ответственной за хранение: взять юридическое лицо и реквизиты из своего договора/кабинета Selectel |
| Государственные и муниципальные системы | Отдельный раздел формы относится к данным в таких системах. Сам по себе учебный VPS к ним не относится; не подставлять сюда список всех сервисов курса |

Перечень выше проверен по бумажному варианту; форма после входа через ЕСИА может отличаться. Вход и окончательную подачу выполняет владелец. Не отправлять форму с догадками или незаполненными существенными сведениями.

## Что удалось установить по дате

В сохранённом журнале маршрутизации TLS найдены соединения с SNI `evgeniikotsur.ru` уже 31 октября 2026 года, начиная с 03:00:14 МСК. Проверялся домен, наружу выводились только диапазоны дат. Журнал фиксирует адрес соединения, поэтому обработка технических сведений существовала до планового открытия заявок 16 ноября.

31 октября — начало сохранившегося диапазона ротации, не доказанная дата первого запуска. Даты создания каталогов nginx и сайта также не устанавливают первый фактический запрос. Для точной даты нужны более ранние документы запуска или журналы, если они сохранились у владельца. Наличие соединений не подтверждает получение заявок на курс; по словам владельца их ещё не было.

## Отдельно о передаче в иностранные сервисы

На [официальной странице трансграничного уведомления](https://pd.rkn.gov.ru/cross-border-transmission/form2/) сейчас предлагается подача через ЕСИА и образец заполнения. Обычное уведомление оператора эту процедуру не заменяет. До отправки персональных сведений учащихся определить действительных получателей, страны, объём данных и применимые условия. Юридический адрес компании не доказывает местонахождение всех её серверов.

На [странице РКН о порядке передачи](https://pd.rkn.gov.ru/cross-border-transmission/) отдельно описан срок для стран без адекватной защиты. Его применимость и календарь действий нужно определить по подтверждённым странам; не считать саму подачу безусловным разрешением на немедленную передачу.

## После подачи

Сохранить копию, номер и дату уведомления в закрытой папке учёта. Проверять статус по официальному сервису, сохранить итоговые регистрационные сведения. Внести их в карточку организатора; при необходимости обновить публичную политику после проверки фактических сведений. Ни один из этих шагов ещё не выполнен.
