## Как подать

На [официальной странице выбора способа](https://pd.rkn.gov.ru/operators-registry/notification/form/) есть три варианта:

- Через подтверждённую учётную запись Госуслуг: после заполнения и отправки бумажная копия не требуется. Это предлагаемый путь для владельца, если такая запись есть.
- С усиленной квалифицированной электронной подписью. Установка средств подписи ради этого проекта не выполнялась.
- Бумажный вариант: отправка электронной формы с последующей печатью, подписью и направлением в территориальный орган. Кнопка подготовки к печати одновременно отправляет электронное уведомление; это не локальный предварительный просмотр.

На портале отдельно предупреждено об общедоступности сведений об ответственном за обработку. Контакты для такого поля нужно проверить перед отправкой. Личные адрес и телефон находятся только в закрытой карточке организатора; в Git их нет.

## Отдельно о передаче в иностранные сервисы

Этот раздел хранит порядок проверки прежней схемы. По новому решению владельца Google, Gmail и Telegram исключаются из процесса после перехода на выбранную российскую почту/облако и MAX; отдельная подача о трансграничной передаче для реально работающей схемы без такой передачи не планируется. Это не удаляет сведения об отсутствии передачи из основного уведомления и не меняет задним числом прошлые операции.

14 ноября по официальным документам подготовлена [карточка получателей Google и Telegram](получатели-и-передача-данных.md): подтверждённые наименования, границы сведений о странах, состав данных курса и готовые вопросы провайдерам. Запросы не отправлены; полный перечень стран для конкретных аккаунтов ещё не подтверждён.

На [официальной странице трансграничного уведомления](https://pd.rkn.gov.ru/cross-border-transmission/form2/) сейчас предлагается подача через ЕСИА и образец заполнения. Обычное уведомление оператора эту процедуру не заменяет. До отправки персональных сведений учащихся определить действительных получателей, страны, объём данных и применимые условия. Юридический адрес компании не доказывает местонахождение всех её серверов.

На [странице РКН о порядке передачи](https://pd.rkn.gov.ru/cross-border-transmission/) отдельно описан срок для стран без адекватной защиты. Его применимость и календарь действий нужно определить по подтверждённым странам; не считать саму подачу безусловным разрешением на немедленную передачу.

Внести их в карточку организатора; при необходимости обновить публичную политику после проверки фактических сведений. Ни один из этих шагов ещё не выполнен.
