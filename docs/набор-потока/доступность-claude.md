# Доступность Claude — решение перед набором

Проверено 14 ноября 2026 года. Основной сервис курса по решению владельца — Claude, подписка Pro нужна к модулям 4–5. На лендинге указаны отдельная оплата и дата 19 декабря, но ещё не разъяснено ограничение доступности по странам.

В [политике поддерживаемых регионов Anthropic](https://www.anthropic.com/legal/supported-regions), действующей с 12 ноября, Россия отсутствует. Политика распространяет ограничения на приложения, API и модели через облачные платформы и уполномоченных посредников; учитывается фактическое местонахождение пользователя. Поэтому наличие иностранной карты или оплаченной подписки само по себе не подтверждает допустимость доступа из РФ.

## Варианты для решения владельца

| Вариант | Последствия для курса |
| --- | --- |
| Сохранить Claude | Программа остаётся прежней. До счёта проверяется возможность пользоваться сервисом по его правилам. На сайте прямо раскрывается региональное ограничение; участию из РФ нельзя обещать работоспособный Claude |
| Подготовить основной путь для РФ, Claude оставить дополнительным | Рекомендация для набора российских проектировщиков. Сначала нужен практический пилот другого сервиса, затем согласование изменённых модулей, требований, расходов и формулировок лендинга. Эквивалентность и прежние сроки пока не подтверждены |

Кандидат для пилота — Алиса AI Про в Yandex AI Studio. В [официальной документации проектов](https://aistudio.yandex.ru/ru/docs/alice-ai-pro/operations/projects) описаны общие чаты и файлы; [описание рабочего места](https://aistudio.yandex.ru/ru/docs/alice-ai-pro/concepts/workplace-project-chat) предусматривает предоставление среды администратором организации. Это не подтверждает такую же функциональность, тариф и простоту подключения, как у личной подписки Claude Pro. Платные услуги не подключались.

Пилот должен проверить на учебных материалах: устойчивые инструкции ассистента, повторное использование файлов, ответы с проверяемыми ссылками на исходник, работу с русским PDF и фрагментом чертежа, сохранение проекта и понятное подключение ученика. Тариф и необходимые статусы аккаунта сверяются до обещания нового варианта покупателям. Конфиденциальные рабочие чертежи в пилот не загружаются.

## Подготовленное предупреждение для лендинга

> Claude доступен только в поддерживаемых Anthropic странах; Россия в список не входит. Перед оплатой курса уточните у Евгения, сможете ли вы выполнять практику модулей 4–5 с учётом правил сервиса. Одна покупка подписки не гарантирует доступность.

Это текст для согласования вместе с выбором учебного пути. На сайт он ещё не перенесён. Обязательная подписка, утверждённые PDF и программа без решения владельца не заменены. Проверку регионального доступа следует завершить до первого счёта.
